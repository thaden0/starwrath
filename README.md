# StarWrath (prototype)

A slow-paced, spacefaring RTS inspired by classic macro/eco-heavy strategy games. Built with Next.js, Phaser, Socket.IO, MySQL (hooks), and Bootstrap.

## Quick start
1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Open http://localhost:3000

See `instructions.txt` for environment variables, Docker usage, and required art assets.
